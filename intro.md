### What is sql?
Sql is a structured query language, used to interact with relational databases 

### What is Database ?
It is a system for storing and retrieving a data.

Keywords to be mostly used in SQL 

- SELECT
- UPDATE
- INSERT INTO
- DELETE
- CREATE DATABASE
- ALTER DATABASE
- CREATE TABLE
- ALTER TABLE
- DROP TABLE
- CREATE INDEX
- DROP INDEX

```SQL
SELECT * FROM TABLENAME; -- SELECT ALL
SELECT COLUMN_NAME1, COLUMN_NAME2 FROM TABLENAME; -- SELECT DATA BASED ON COLUMNS
SELECT DISTINCT COLUMN_NAME1 FROM TABLENAME;
SELECT DISTINCT COLUMN_NAME1, COLUMN_NAME2 FROM TABLENAME; -- RETURN COMBINATION OF UNIQUE COLUMNS ROWS
SELECT COUNT(*) FROM TABLENAME; -- Taking the count
SELECT COUNT(DISTICT COLUMN_NAME1) FROM TABLENAME; -- TAKE THE DISTINCT COUNT FROM THE TABLE
SELECT * FROM TABLENAME WHERE COLUMN_NAME = "STRING" || NUMBER
```
